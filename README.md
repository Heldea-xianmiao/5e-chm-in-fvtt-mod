# 5E不全书 FVTT 内部部署 (5e-chm-in-fvtt)

这是一个将知名的中文 DND 5E 参考资料“5E不全书”直接集成到 Foundry VTT 中的模组。它不是简单的网页嵌入，而是包含了一系列针对 FVTT 环境的深度优化和功能增强。

## ✨ 功能特性

- **无缝集成**：在 FVTT 内部以独立窗口打开不全书，无需切换浏览器。
- **智能导航**：修复了原版 CHM 网页在嵌套 Frame 环境下的导航问题，支持深层链接自动修复（如法术速查跳转）。
- **即时引用**：
  - 在不全书窗口中选中一段文本。
  - 按住 **`Alt`** 或 **`Ctrl`** 键松开鼠标。
  - 内容（保留排版格式）将会直接发送到聊天栏，并附带来源章节。
- **便捷入口**：
  - 核心日志目录（右侧）- 顶部的快速入口按钮。
  - 快捷键：**`Alt + B`** 快速切换显示/隐藏。

## 📥 安装

1. 将本模组文件夹 `5e-chm-in-fvtt` 放入你的 FVTT 用户数据目录的 `Data/modules/` 下。
2. 启动 FVTT 并在“管理模组”中启用它。

## 🔄 如何更新内容（由用户自行维护）

本模组本身主要提供“容器”和“功能脚本”，不全书的具体内容数据来源于 [DND5eChm 项目](https://github.com/DND5eChm/DND5e_chm)。你可以通过以下步骤保持内容的最新状态：

1. **下载源文件**：
   前往 [DND5e_chm GitHub 仓库](https://github.com/DND5eChm/DND5e_chm)，下载最新的仓库文件（Clone 或 Download ZIP）。

2. **覆盖文件**：
   将下载得到的文件夹内的所有内容（除了 `.wcp` 工程文件外，主要是 `index.html`, `topics/`, `icons/` 等）复制并覆盖到本模组目录下的 **`chm/`** 文件夹中。

3. **执行修复脚本** (🚨 重要步骤)：
   在模组根目录下找到并双击运行 **`update.bat`**。
   
   > **为什么需要这一步？**
   > 原版 CHM 网页是为了 IE内核设计的（包含旧版 DOCTYPE 和不兼容的 JS 写法），直接在现代浏览器或 FVTT 中运行会出现乱码、排版错乱或无法跳转的问题。`update.bat` 会自动调用 PowerShell 脚本对这些文件进行批量“现代化改造”，包括：
   > - 修复 DOCTYPE 为 HTML5 标准模式。
   > - 注入 FVTT 专用的交互逻辑（用于引用功能）。
   > - 修复 Frame 框架下的路径跳转 Bug。

## 🛠️ 技术细节

- 兼容性：Foundry VTT v13 / v14
- 依赖系统：dnd5e (建议 4.x / 5.x)
- 编码：项目通过脚本强制处理了 UTF-8 与 GBK 的兼容性问题，确保在不同环境下字符显示正常。
